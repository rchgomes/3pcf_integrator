# Generating training data for emulator

Usage:
```
cosmosis sobol.ini
```

This will use `list` sampler, which use the model parameters listed in a user specified file. 
This file must be in the cosmosis chain format: include the names of model parameters in the first line as header.

The other parameters which are not specified in the list file are fixed to the typical values in value file.

This will create the output with extra_output of predictions of map3, which is told to cosmosis by the `pipeline/extra_output` option.
Because this data, `map`, is the 1d array data, we need to tell cosmosis the dimension of it by adding a suffix like `#4`, telling the dimension is 4 in this case.

In our case, Sunao prepared the list file in the cosmosis format based on the pkl file generated by Rafael at
`data/nz/sobol_sequence_s8om.txt`. This file can be created by running a script at `script/sobol_pkl_to_txt.py`.
And the other values are specified in `config/emulator-train/values.ini` where 
they are fixed to the values of CosmoGrid sim.
