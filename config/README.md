# config directories

## Contents
### [test-first-run](test-first-run)
This is very old run. We did not include even NLA. and pipeline no longer work with this.

### [test-second-run](test-second-run)
Includes NLA

### [test-baryon-run](test-baryon-run)
Stress test for baryon systematics. Simulated the baryon effect from OWLS-AGN. 
For map3, we simulated it by rescaling the baryon factor estimated for TNG-300 in bihalofit paper, 
where rescaling factor is estimated from 2pt.

### [test-wcdm-run](test-wcdm-run)
Assessment of constraining power on wCDM.

### [test-desy3c-run](test-desy3c-run)
Now we use DES-Y3 cosmological parameter as input cosmological parameters, 
so 'desy3c' indicates DES-Y3 cosmology. This is more reasonable test, because 
we would get contour around the DES Y3 2pt cosmic shear best-fit params.

### [test-desy3c-baryon-run](test-desy3c-baryon-run)
Same as [test-baryon-run](test-baryon-run) but using DES-Y3 cosmology for input.

### [test-desy3c-emu-run](test-desy3c-emu-run)
Same as [test-desy3c-run](test-desy3c-run), but using the emulator.
The result of this run is supposed to agree with that of [test-desy3c-run](test-desy3c-run).
We use this for validation of emulator and pipeline.

### [test-desy3c-wcdm-run](test-desy3c-wcdm-run)
Same as [test-desy3c-run](test-desy3c-run), but sampling wCDM.

### [emulator-train](emulator-train)
configs to generate the training dataset for emulator.

### [test-desy3c-emu-run](test-desy3c-emu-run)
Same analyses as in [test-desy3c-run](test-desy3c-run), but replacing map3 part with its emulator. 
From here, all the analyses are based on this emulator as otherwise noted.

### [test-desy3c-moped-run](test-desy3c-moped-run)
Analyses using the moped data compression. The purpose of these analyses is to see how losslessly 
constrain the cosmological parameter using the MOPED data compression.
The transformation matrices used to compress the data vector are generated by the configs in 
[moped-compress](moped-compress).

### [test-desy3c-joint-run](test-desy3c-joint-run)
For the joint analysis of 2pt and map3. Until here, we assumed that the 2pt and map3 data vector
does not correlate, to have zero cross covariance between them. From here, we rerun the analysis by including the cross-covariance.

### [test-desy3c-moped-joint-run](test-desy3c-moped-joint-run)
Performing the MOPED data compressions to 2pt and map3 independently, and then combine their 
compressed data vector in a joint analysis.
This indicates that the transformation matrix for 2pt(map3) is defined using the 2pt(map3) 
auto-covariance, and does not take care of the correlation between them. However,
the final likelihoods includes the cross-covariance. In this sense, the transformation matrix
is not optimal, but the cross-correlation is proprtly propagated to cosmological paramter constraint.

Althought the compression is not optimal, but is useful since we can split the constraining power 
into 2pt and map3 components.

### [test-desy3c-joint-moped-run](test-desy3c-joint-moped-run)
Performing the joint firstly, then compression. The transformation matrix is defined using the full-covariance
of 2pt and map3, and the compression is optimal (compared to the previous [test-desy3c-moped-joint-run](test-desy3c-moped-joint-run)).
